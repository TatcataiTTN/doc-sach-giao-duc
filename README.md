# Đọc sách Khoa học Giáo dục

Ghi chép đọc sách bằng tiếng Việt, chia theo cuốn, theo chương và theo mục, kèm thuật ngữ Anh–Việt và trắc nghiệm tự kiểm tra. Site tĩnh dựng bằng Hugo (không dùng theme).

Đây là bản diễn giải học tập, **không phải bản dịch nguyên văn** và không thay thế sách gốc. Sách gốc là tác phẩm có bản quyền của tác giả và nhà xuất bản. Chủ sở hữu bản quyền muốn gỡ hoặc sửa nội dung xin mở một issue trong kho này.

## Chạy cục bộ
```bash
hugo server
```
Kho này chỉ chứa phần site. File PDF sách, văn bản OCR và ghi chú đọc không được đưa lên đây.
